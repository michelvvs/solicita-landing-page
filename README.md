# Solicita - Plataforma de Inteligência e Auditoria de Editais com IA

> Landing Page Institucional & Demonstração Interativa do **Dossiê Premium 360°** e **Agentes de Inteligência Artificial** para Licitações Públicas (Lei nº 14.133/2021).

---

## 🚀 Visão Geral

O **Solicita** une quase duas décadas de experiência prática nos maiores pregões e concorrências públicas do Brasil com tecnologia de ponta em Inteligência Artificial, auditando editais em **18 dimensões críticas**.

### Principais Recursos da Plataforma:
- **Dossiê 360° Explorer**: Navegação detalhada pelas 18 dimensões de análise de risco e viabilidade.
- **Achados Críticos**: Matriz de riscos categorizados por gravidade (🔴 Bloqueante, 🟠 Crítico, 🟡 Atenção, 🟢 Oportunidade) com embasamento jurídico e jurisprudência do TCU.
- **Simulador Interativo de Editais**: Demonstração de diagnósticos reais em Obras, TI, Serviços Continuados e Saúde.
- **Ecossistema de Agentes de IA**: Agentes especializados (Edital Reader, Vícios & Pegadinhas, Engenharia de Preços, Recursos & Impugnações, etc.).
- **Tabela Comparativa**: Análise Tradicional vs. Ecossistema Solicita.
- **Calculadora & Planos de Investimento**.

## 📦 Como Rodar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU-USUARIO/solicita.git
   cd solicita
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Build para produção:**
   ```bash
   npm run build
   ```
